# 蓝色星原：旅谣 简体汉化/尔安

台服游戏、台服启动器及日服启动器的简体中文汉化与还原工具。首次正式发布版本：**v1**。

> **开服后若登录异常请还原文件，此脚本未进行反作弊验证。**

## 下载与使用

前往 [Releases](https://github.com/xiayuan0817/Azur-Promilia-Chinese-Translation-Script/releases/latest)，下载 `AzurPromilia-Localization-Full-v1.zip` 并完整解压。关闭游戏及启动器（包括托盘图标），双击 `双击运行-汉化或还原.bat`。

- 输入 `1` 并回车：汉化。
- 输入 `2` 并回车：还原。
- 自动识别台服游戏、台服启动器和日服启动器，也可选择单个项目。

完整包包含全部 22 个替换资源文件，无需国服包体或 Python。找不到路径时，将安装文件夹拖到 BAT 图标上运行。

## 最终版源码

仓库保留正式使用的最终版源码及说明：

| 文件 | 用途 |
|---|---|
| `双击运行-汉化或还原.bat` | 双击运行入口 |
| `tools/Apply-OfficialZH.ps1` | 自动定位、校验、备份、汉化和还原 |
| `tools/deployment-plan.json` | 版本、替换路径和 SHA-256 校验清单 |
| `build_release.py` | 校验替换资源并构建独立发行包 |
| `使用说明.txt` | 简明使用方法 |

完整汉化包统一放在 Releases。仓库源码中不包含游戏替换资源，直接下载仓库源码不能完成汉化；普通用户请下载上述完整包。

## 重新打包

维护者使用 Python 3.11 或更高版本，将完整包中的 `payload` 文件夹作为输入：

```powershell
python build_release.py --payload "D:\汉化包\payload" --output ".\dist"
```

脚本逐项验证 22 个替换文件的 SHA-256，生成独立 ZIP 和 `SHA256SUMS.txt`；已有同名 ZIP 时停止，避免覆盖。
