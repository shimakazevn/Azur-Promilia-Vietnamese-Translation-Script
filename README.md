# 蓝色星原：旅谣 简体汉化/尔安

台服游戏、台服启动器及日服启动器的简体中文汉化与还原工具。

> **开服后若登录异常请还原文件，此脚本未进行反作弊验证。**

## 下载与使用

进入本仓库右侧的 **Releases（发行版）**，下载 `AzurPromilia-Localization-Full-v6.zip`，完整解压，关闭游戏和启动器后，双击 `双击运行-汉化或还原.bat`。

- 输入 `1` 并回车：汉化。
- 输入 `2` 并回车：还原。
- 自动识别台服游戏、台服启动器、日服启动器；也可以选择单个项目。

**完整安装包已包含全部 22 个替换资源文件、运行脚本、校验清单和使用说明，无需另找 payload，无需安装 Python。**

## 完整项目内容

- `AzurPromilia-Localization-Source-v6.zip`：本次汉化工程的资源分析、转换、审计、构建、测试及部署源码，保留原有 `work/` 目录结构。
- `tools/Apply-OfficialZH.ps1`：正式部署脚本。
- `tools/deployment-plan.json`：支持版本、文件路径与 SHA-256 校验清单。
- `双击运行-汉化或还原.bat` 与 `使用说明.txt`：用户入口和简明说明。
- Release 的 `AzurPromilia-Localization-Full-v6.zip`：完整可运行汉化包，包含 `payload/` 全部资源。

源码中部分分析脚本保留开发时的游戏安装路径，重新分析或从原游戏重新生成资源前，应按自己的安装目录调整。Release 安装包会自动识别路径。
